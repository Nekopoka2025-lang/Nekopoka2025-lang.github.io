代码好不好读？

行内代码长这样：把构建命令写成 npm run build，把文章放进 posts/ 目录。

一段用来计算贴纸旋转角度的小函数：

function rotation(slug) {
  let h = 0;
  for (const ch of slug) {
    h = (h * 31 + ch.charCodeAt(0)) >>> 0;
  }
  return (h % 31) - 15;
}

console.log(rotation("hello-world"));

以及一小段样式，正好对照站点里的贴纸规则：

.sticker {
  background: #fff;
  padding: 10px 22px;
  border-radius: 18px;
  box-shadow: 3px 4px 0 #0003;
}

清单与引用

构建一篇新文章大约只要三步：

  1. 在 posts/ 里新建 Markdown，写好 frontmatter。
  2. 运行 npm run build。
  3. 打开 docs/ 里生成的页面看一眼。

测试通过的标准很朴素：代码能复制，图片能显示，手机上也能把这张纸读完。

若你正在写下一篇，记得在 site.config.json 里先确认站点名和作者。然后，去所有文章看看筛选和排序是否也工作正常。
